# OmaBridge research

This directory holds the background research and proposed architecture that preceded the implementation. Proposals here are not commitments; see the top-level README for what is implemented.

- [Architecture study](architecture-study.md): product interpretation, researched alternatives, proposed trust model and SDK, mobile/browser limitations, risks and future evaluation gates.
- [SDK contract proposal](sdk-contract-proposal.md): semantic operations, pairing/connection states, authority and recovery choices, cross-application trust boundaries, transport gates and acceptance scenarios.
- [Source ledger](sources.json): the sources cited by the study.
- [Retrieval manifest](source-manifest.json): evidence hashes and separately observed upstream branch tips at the time of the study.

Upstream documentation is evidence of upstream claims, not independent runtime validation.
